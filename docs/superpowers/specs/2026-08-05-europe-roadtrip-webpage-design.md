# 欧洲自驾游旅行网页 — 设计文档

**日期**: 2026-08-05
**来源计划**: `欧洲自驾游行程计划.xlsx`（7天6晚，9月30日–10月6日）
**交付物**: 单个自包含 HTML 文件 `index.html`，双击即开，可离线分享

## 1. 目标与背景

用户制定了一份 7 天 6 晚欧洲五国自驾行程（巴黎→布鲁塞尔→阿姆斯特丹→科隆→卢森堡→凡尔赛→巴黎→北京，途经法国/比利时/荷兰/德国/卢森堡，总里程 1,502km），需要将 Excel 计划转化为一个精美网页，参考一流旅行网站/博客的观感，苹果风设计，核心展示：整体路线图、每日行程、风土人情、游玩名胜、预算与实用信息。

**用户已确认的决策**:
- 路线图：SVG 矢量总览图 + Leaflet/OSM 交互地图两者结合
- 图片：在线高清图（Wikimedia Commons 等免费图源）+ 加载失败降级为渐变占位卡
- 语言：中文为主

## 2. 设计语言（苹果风）

- 浅色主题：背景 `#f5f5f7`（苹果官网灰）、文字 `#1d1d1f`、点缀色苹果蓝 `#0071e3`
- 系统字体栈：`-apple-system, BlinkMacSystemFont, "SF Pro Display", "PingFang SC", "Microsoft YaHei", sans-serif`（无需联网）
- 排版：hero 大标题 48–64px、字距 -0.02em、正文 15–17px 行高 1.6
- 卡片：大圆角 20–28px、细边框 `1px solid rgba(0,0,0,0.06)`、hover 轻微上浮 + 阴影
- 吸顶导航：毛玻璃 `backdrop-filter: blur(20px)` + `rgba(255,255,255,0.8)` 背景
- 动效：IntersectionObserver 滚动渐入、SVG 路线描线动画、平滑锚点滚动
- 每城市/国家有专属渐变色，贯穿该板块（法国蓝白红、荷兰橙、德国黑红金、比利时黑黄红、卢森堡浅蓝红）

## 3. 页面结构（9 板块）

1. **Hero 封面** — 巴黎天际线背景图 + 标题「欧洲自驾 · 七日五国」+ 数据条（7天 / 5国 / 1,502km / 6晚 / 22h驾驶）
2. **整体路线图** — 手绘感 SVG：巴黎→布鲁塞尔→阿姆斯特丹(风车村)→科隆→卢森堡→凡尔赛→巴黎。城市圆点、弧线路径、每段距离标注、描线动画、点击城市跳转到对应行程板块
3. **交互地图** — Leaflet 1.9 + OSM 瓦片，全部城市 marker + 路线 polyline（含风车村往返），与 SVG 总览图视觉一致；地图加载失败时整个板块隐藏（SVG 仍可用）
4. **每日行程 ×7** — 每板块：日期徽标（第X天 + 日期）、当日主题标题、里程标签、景点画廊（照片卡 + 名称 + 星级贴士）、美食卡（餐厅 + 招牌菜 + 人均）、可展开完整时刻表（Excel 全部时段记录，含时间/类型/地点/详情/贴士）
5. **国家风情 ×5** — 法/比/荷/德/卢文化卡：典型生活方式、必尝美食、特色体验
6. **预算** — Excel 预算表可视化：分类卡片（租车/燃油/过路费/停车/酒店/餐饮/门票）+ 人均总计 €1,540–2,300
7. **必提前预订** — 7 项清单（租车、梵高博物馆、安妮之家、罗浮宫、凡尔赛宫、Rijksmuseum、餐厅），含提前时间与价格
8. **实用贴士** — 签证/限速/停车/加油/天气/货币/手机/保险 8 张网格卡片
9. **返程页脚** — 10/6 22:00 CDG→北京 ✈️，时差 -7h，预计 10/7 中午抵达

导航锚点：路线 / 行程 / 风情 / 预算 / 预订 / 贴士

## 4. 数据层

所有行程数据以 JS 对象数组内联于 HTML：`days[]`（每日标题/日期/主题/里程/景点/餐饮/时刻表）、`drives[]`（驾驶段：起终点/距离/时间/高速/途经）、`budget[]`（分类/单价/范围）、`bookings[]`、`tips[]`、`countries[]`。数据逐条来源于 Excel，零遗漏（69 条时段记录全部保留在可展开时刻表中）。

## 5. 技术方案

- 纯原生 HTML/CSS/JS，无构建步骤
- Leaflet 1.9.x 从 unpkg CDN 引入（CSS+JS），OSM 标准瓦片；无网络时该板块隐藏
- 图片：Wikimedia Commons `Special:FilePath` 稳定引用免费高清照片（实现时逐张验证 URL），统一 `onerror` 降级为 `linear-gradient` + 景点名占位卡；预选 15–20 张（铁塔、罗浮宫、凯旋门、蒙马特、圣母院、奥赛、布鲁塞尔大广场、撒尿小童、风车村、运河、水坝广场、国家博物馆、安妮之家、科隆大教堂、爱情锁桥、卢森堡峡谷、凡尔赛宫、塞纳河、杜乐丽、圣礼拜堂）
- SVG 路线图手工绘制：`viewBox` 固定，路径用平滑二次贝塞尔曲线，城市节点用真实坐标比例投影（欧洲地图约 47°N–53°N, 0°–7°E 区域）
- 响应式：375px 移动端 ~ 1440px 桌面；移动端行程画廊改为单列

## 6. 错误处理与降级

- 图片加载失败 → 渐变占位卡（不破版）
- Leaflet/OSM 不可用 → 隐藏交互地图板块，SVG 总览正常
- 无 JS → 页面仍显示静态内容（内容以 HTML 呈现，JS 仅增强）
- 字体不加载 → 系统字体栈兜底

## 7. 验收标准

1. 双击打开 `index.html` 正常显示全部 9 板块
2. 中文文案，苹果风视觉（浅色、大圆角、毛玻璃导航、平滑动画）
3. SVG 路线图完整呈现全部 7 城 + 风车村 + 分段距离
4. 每日行程含全部 69 条 Excel 时段记录，信息零遗漏
5. 图片失败时页面无破版
6. 移动端（375px）无横向滚动
7. 离线打开（无网络）页面仍完整可用（仅缺在线图片与交互地图）

## 8. 范围外（YAGNI）

- 不做多页面/博客系统、不做后端、不做多语言切换、不做照片上传功能
- 不引入构建工具与框架
